# ADR-005: Production storage and backup

- Status: Proposed
- Date: 2026-09-18

## Context

Blak Workspace seeds an Indigenous-branded overlay on openDesk. Foundational choices must be explicit before implementation spreads.

## Decision

Production must use external PostgreSQL/MariaDB/object storage per upstream guidance; backups follow the upstream data-storage inventory; restore is rehearsed before pilot.

## Consequences

More operable DR; eval bundled services forbidden in prod; requires hosting decisions before apply.
