# ADR-004: Licensing boundary

- Status: Proposed
- Date: 2026-09-18

## Context

Blak Workspace seeds an Indigenous-branded overlay on openDesk. Foundational choices must be explicit before implementation spreads.

## Decision

Keep original Blak/Yuma overlay under Apache-2.0; never relicense upstream apps; maintain NOTICE and THIRD_PARTY_NOTICES with honest gaps.

## Consequences

Public OSS overlay possible; enabling AGPL/GPL components increases compliance obligations; OX remains optional.
