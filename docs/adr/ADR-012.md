# ADR-012: Sites as aggregation layer with provider interfaces

- Status: Accepted
- Date: 2026-09-19

## Context

Teams need a coherent place for program and business information (pages, libraries, lists, membership, search) without cloning Microsoft SharePoint or duplicating Nextcloud, Collabora, Docmost, OpenProject, Element, or Jitsi. Identity is already Nubus/OIDC (ADR-003). Knowledge is Docmost (ADR-010). AI stays off by default (ADR-011). Sites must ship as a profile-flagged overlay, default off, with no invented image digest and no mandatory public-cloud egress.

Live eval SSO, Collabora round-trip, and multi-arch Helm apply are out of reach for this seed (paid/prod-adjacent cluster). The foundation still has to be testable: RBAC, templates, page revisions, Nextcloud library metadata, list lookup protection, security-trimmed search, provider deep-links, audit without document bodies, OpenAPI operations that call the same store as the UI, and Helm values for linux/amd64 plus linux/arm64 with `egress.mandatory` false.

## Decision

- **Blak Sites** is the product label. Internal id stays `sites`. Helm release/OIDC client names are not renamed here.
- Sites is an aggregation, permissions, and presentation layer. Binaries stay in Nextcloud (`FileProvider`). Knowledge, projects, chat, and meet are deep-links (`docmost`, `openproject`, `element`, `jitsi`), not forks.
- SSO is Nubus OIDC. Authorization is server-side. Frontend-hidden controls are still denied by the API.
- Default eval/staging/prod profiles keep `sites.enabled: false` and `allowPublicForms: false`. Public/anonymous forms and XWiki as `KnowledgeProvider` fail validation.
- Helm chart targets `linux/amd64,linux/arm64`. Image tag is TBD until pinned. Core UI has no mandatory egress after install.
- OpenAPI (`/api/v1`) is the same membership and list surface the UI uses.
- This is not SharePoint feature-parity, not multi-tenant SaaS, and not an IRAP/PROTECTED claim.

## Consequences

Operators can review the Sites contract and enable it behind a profile flag after image pin, Nubus SSO, and pilot acceptance. Child issues still split pages, libraries, lists, search, and automations. Live cluster smoke waits on an eval environment that is not this seed.
