# ADR-009: Optional component profiles

- Status: Proposed
- Date: 2026-09-18

## Context

Blak Workspace seeds an Indigenous-branded overlay on openDesk. Foundational choices must be explicit before implementation spreads. Blak Knowledge uses Docmost (BW-055), not XWiki, in Blak defaults.

## Decision

OX mail/calendar, Entra, AI features, Blak Flow, and Blak Hermes stay disabled by default behind explicit profile flags and decisions. XWiki stays off in Blak defaults; Docmost is enabled only after BW-055 pin and licence review, never alongside XWiki. Hermes document search is a further opt-in on top of `hermes.enabled` (ADR-011).

## Consequences

Smaller pilot surface; some customers wait for optional stacks; licence reviews gated.
