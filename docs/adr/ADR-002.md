# ADR-002: Deployment isolation model

- Status: Proposed
- Date: 2026-09-18

## Context

Blak Workspace seeds an Indigenous-branded overlay on openDesk. Foundational choices must be explicit before implementation spreads.

## Decision

One customer organisation per deployment; separate eval/staging/prod profiles; no shared-db multi-tenant pilot.

## Consequences

Stronger isolation and simpler compliance story; higher ops cost per customer; fleet design deferred to BW-054.
