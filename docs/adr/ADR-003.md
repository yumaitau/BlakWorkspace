# ADR-003: Identity and federation baseline

- Status: Proposed
- Date: 2026-09-18

## Context

Blak Workspace seeds an Indigenous-branded overlay on openDesk. Foundational choices must be explicit before implementation spreads.

## Decision

Use Nubus (Keycloak/OpenLDAP/portal) as mandatory baseline IdP; treat Microsoft Entra as optional investigation only.

## Consequences

Fastest path to working SSO with openDesk; Entra customers need a later federation project.
