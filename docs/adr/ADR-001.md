# ADR-001: Upstream release and overlay strategy

- Status: Proposed
- Date: 2026-09-18

## Context

Blak Workspace seeds an Indigenous-branded overlay on openDesk. Foundational choices must be explicit before implementation spreads.

## Decision

Pin a single openDesk deployment tag and apply Blak changes as overlays/config rather than a long-lived hard fork of charts. The seed pin is openDesk `v1.18.2` commit `eab2ee774187308f82307f0daaf1471dfe560f34` (2026-09-11), recorded in [docs/upstream-baseline.md](../upstream-baseline.md).

## Consequences

Upgrade path stays close to ZenDiS releases; some features may wait for upstream hooks; patch labelling required if unavoidable.
