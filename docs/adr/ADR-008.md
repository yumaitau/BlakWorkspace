# ADR-008: Regional data flows

- Status: Proposed
- Date: 2026-09-18

## Context

Blak Workspace seeds an Indigenous-branded overlay on openDesk. Foundational choices must be explicit before implementation spreads.

## Decision

Target Australian residency for primary stores; document egress; make no PROTECTED/IRAP/sovereignty certification claims.

## Consequences

Clearer customer conversations; hosting still undecided; egress to registries may remain.
