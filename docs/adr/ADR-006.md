# ADR-006: Branding approach

- Status: Proposed
- Date: 2026-09-18

## Context

Blak Workspace seeds an Indigenous-branded overlay on openDesk. Foundational choices must be explicit before implementation spreads.

## Decision

Brand via upstream theming hooks and label maps; do not rename internal IDs; cultural assets require provenance and review. Hook inventory: `theme.yaml.gotmpl` / `helmfile/files/theme`, portal `portalStylesheets.css`, `functional.portal` (see [docs/brand/theme-hooks.md](../brand/theme-hooks.md)).

## Consequences

Upgradeable themes; incomplete per-app theming remains; brand pack dependency.
