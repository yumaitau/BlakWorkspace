# ADR-010: Docmost for Blak Knowledge

- Status: Accepted
- Date: 2026-09-18

## Context

openDesk ships XWiki as knowledge management. Blak Knowledge is a product label. XWiki licence and operations cost are the wrong default for this overlay. Docmost is the chosen wiki for Blak defaults (BW-055). Image digest, exact licence/edition, and any paid SSO features are not yet pinned.

## Decision

- Supported Blak profiles that include Knowledge deploy **Docmost**, not XWiki.
- XWiki stays off in Blak defaults. Dual-enable is invalid except a documented migration profile (none is provided in this seed).
- Licence boundary: record Docmost's upstream licence at pin in THIRD_PARTY_NOTICES; overlay remains Apache-2.0; do not relicense Docmost.
- Image pins: explicit gap until a real tag/digest is copied from upstream evidence. Do not invent digests.
- SSO approach: Nubus/Keycloak OIDC (ADR-003). Do not enable public unauthenticated spaces. Guest/external sharing follows BW-023 when that work exists.
- Calling the profile "supported" for production still requires owner licence/SSO confirmation (decision-log). Until then Knowledge stays disabled on default eval/staging/prod flags, with `knowledge-docmost.example.yaml` as the enablement sketch.

## Consequences

Greenfield Knowledge is Docmost-only. Operators keep Knowledge off rather than falling back to XWiki. Live create/deny and backup smoke wait on an eval cluster and on BW-019/BW-020.
