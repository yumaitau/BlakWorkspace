# ADR-007: Indigenous governance boundary

- Status: Proposed
- Date: 2026-09-18

## Context

Blak Workspace seeds an Indigenous-branded overlay on openDesk. Foundational choices must be explicit before implementation spreads.

## Decision

No fabricated cultural assets or endorsements; cultural and community-facing content requires needs:cultural-review; governance docs define process.

## Consequences

Protects trust; may slow brand publication; owners must staff review.
