# [BW-056] Expose Hermes as opt-in sovereign AI and document search

## Summary
Deploy Blak Hermes beside the overlay, register it on the Nubus control plane, and allow opt-in search across Drive, Docs, and Knowledge without turning AI on by default.

## Outcome
- Hermes is a profile-flagged sidecar (`hermes.enabled`), default **false**.
- Control-plane registration lives in `deploy/control-plane/hermes.json` (id `hermes`, label Blak Hermes, gateway unpublished).
- Document search requires `hermes.documentSearch` plus corpus flags for Drive/Docs/Knowledge (Docmost, not XWiki).
- Inference default is `owner-chosen`. External SaaS needs `allowExternalInference`.
- Public unauthenticated access and published gateway ports fail validation.
- Portal tile exists, default off.

## Non-goals
- Production apply
- Invented image digests
- IRAP/PROTECTED claims
- Multi-tenant Hermes inside one deployment
- Dual-enable XWiki as a search backend
