# [BW-053] Define opt-in AI policy default off

## Summary
AI processing of customer content stays **off** unless an owner opts in. The Blak runtime for that opt-in is Hermes (BW-056 / ADR-011).

## Policy
- Default eval/staging/prod: `optional.aiFeatures: false`, `hermes.enabled: false`, `hermes.documentSearch: false`.
- Opt-in is explicit profile flags, not a hidden sidecar.
- Document search is not implied by enabling the runtime; it is a second flag.
- No public unauthenticated AI surface.
- No claim of IRAP, PROTECTED, or certified sovereign AI.

## Non-goals
- Production apply
- Invented cultural assets or certification claims
