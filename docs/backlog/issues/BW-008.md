# [BW-008] Define environment profiles eval staging prod

## Problem / outcome
Clear separation of eval/staging/prod overlays prevents accidental prod configuration in experiments.

## Context / upstream evidence
ADR-002 deployment isolation. Assumptions: one customer org per deployment. Profiles include knowledge.xwiki=false and docmost=false until BW-055 enables Docmost alone.

This issue is part of epic BW-E02 under milestone M1.

## In scope
- Three profile stubs
- Diff matrix table
- Promotion rules
- Secrets separation notes
- Exclusive Knowledge engine flags

## Non-goals
- Shared secrets across profiles
- Auto-promote to prod
- Dual-enabling XWiki and Docmost

- No prod secrets in repo
