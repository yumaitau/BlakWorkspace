# [BW-010] Define secrets management approach

## Problem / outcome
openDesk deployments embed many component secrets; Blak overlays need a safe pattern that never commits prod secrets.

## Context / upstream evidence
Upstream GitOps docs warn pre-rendered manifests embed secrets. Use external secret references for staging/prod; sealed/local for eval only as documented.

Part of epic BW-E02 / M2. Australian English. No prod secrets in git or CI.

## In scope
- Secrets inventory categories
- Eval vs staging/prod pattern
- CI secret policy (validation only)
- Rotation notes

## Non-goals
- Committing production secrets
- Printing secrets in logs
- Shared master password in git
