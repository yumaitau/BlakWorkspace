# [BW-001] Define Blak Workspace product contract

## Problem / outcome
Stakeholders need a written product contract stating what Blak Workspace is and is not so distribution stays scoped to branding, config, deploy automation, docs, and carefully scoped extensions on openDesk.

## Context / upstream evidence
Yuma IT distributes an Indigenous-branded digital workplace on ZenDiS openDesk (deployment Apache-2.0). Naming map is labels only: Blak Workspace/suite; Blak Drive/Nextcloud; Blak Docs/Collabora; Blak Notes; Blak Chat/Element; Blak Meet/Jitsi; Blak Mail and Calendar/OX if licensed; Blak Knowledge/Docmost (not XWiki; see BW-055); Blak Projects/OpenProject; Blak Admin; Blak Flow reserved. Do not invent M365 parity or sovereignty certifications.

This issue is part of epic BW-E01 under milestone M0. Work should stay within the Blak Workspace overlay model: branding, configuration, deploy automation, documentation, and carefully scoped extensions on openDesk. Preserve upstream compatibility. Prefer `upstream:configuration` over `upstream:patch`. Australian English for human docs. Do not invent community endorsements, cultural assets, PROTECTED/IRAP claims, or Microsoft 365 parity.

Operators and contributors should treat the acceptance criteria as the definition of done for this seed stage. If upstream evidence changes (new openDesk tag, theming hook, or identity behaviour), update docs/upstream-baseline.md and related ADRs rather than quietly drifting. Licence impact for this item is recorded as `none`; apply `needs:licence-review` when redistribution or copyleft enablement is affected. Cultural or community-facing copy must use `needs:cultural-review`.

Related assumptions include one customer organisation per deployment, Kubernetes with supported Helm/Helmfile, unbranded baseline then Blak overlay, eval/staging/prod profiles, AU hosting intent without paid infra in this seed run, en-AU locale, Nubus identity start, optional Entra investigation only, core pilot workflow focus, and AI off by default for customer content.
